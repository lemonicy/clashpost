# 部落驿站

一个曾经用于整理《部落冲突》资料、机制说明和相关工具的网站，网址：https://clashpost.com

> **项目状态：已停止维护**
>
> 除网站上的安装包下载版块外，本站主体内容和本仓库内容均已停止更新。
> 本仓库目前主要作为历史数据归档，供需要者下载、备份、参考或二次整理使用。

## 项目说明

部落驿站曾经包含以下内容：

* 《部落冲突》安装包下载；
* COC 游戏数据整理；
* 游戏机制讲解与资料文章。

由于个人精力有限，而且开源后也没有招到稳定的维护人员，因此我们决定放弃对网站主体的维护，仅保留安装包版块供玩家下载国际服 coc.

仓库中的数据不再保证时效性、完整性和准确性。使用本项目内容时，请自行判断并核对相关信息。

## 数据下载

如果你需要获取本站已有数据，可以直接下载本仓库内容。

你可以通过 GitHub 页面下载 ZIP 文件，也可以使用以下命令克隆仓库：

```bash
git clone https://github.com/lemonicy/clashpost.git
```

另：在停更之时，网站中的数据是 2026 年 2 月版本的。

## 本地查看

如果你只是想在自己的电脑中看看这个项目，可以按以下步骤运行项目：

1. 下载并安装 [Node.js](https://nodejs.org/en)（需要 Node.js 20.19+ / 22.12+）。

2. 下载本仓库 ZIP 文件并解压，或使用 `git clone` 将项目拉取到本地。

3. 进入项目目录，运行以下命令：

```bash
npm install
npm run docs:dev
```

4. 打开 http://localhost:5173 查看本地页面。

## 贡献与反馈

本站已停止主体维护，ISSUE 入口仅用于以下情况：

- 安装包下载失效；
- 页面存在严重错误；
- 内容涉及侵权、隐私或其他需要下架的问题。

普通资料修订、游戏数据更新、攻略投稿等内容，原则上不再处理。如果你希望继续维护、整理或迁移本站资料，可以基于 GitHub 仓库中的历史数据自行开展，只需说明自己是“部落驿站”的继承者就行。

相关反馈不保证及时回复，也不代表网站会恢复维护。

## 总结

* 网站主体内容不再更新；

* 后续不再接受广告投放或商业合作。
